# FOX OS

ブラウザの机です。起動は中央のハニカムが外側へ溶けて広がります。左上と時計の横は、同じハニカムのリンクロゴです。
Ubuntu 24.04 の ISO 定義は [os/README.md](os/README.md) に残しています。ISO 自体は入っていません。


試せること:

- `ruby -v` / `rails -v`
- `cd sample_app` のあと `bin/rails test` と `bin/rails server`
- アシスタントのコマンドは承認するまで実行しない

固定バージョン: Ruby 3.3.6、Rails 7.2.2、Bundler 2.5.16、mise v2026.2.9。
API キーは含めていません。
