# ジオメトリースタジオ　かんたんリファレンス

このアプリは、円や立方体、クラインの壺を使って、数と形を楽しく見られる「図形の実験室」です。まるで絵の具で絵を描くように、スライダーを動かして形を回したり、時計とつなげたりできます。

- ページURL: `/geometry`
- 主なコード: `src/components/geometry-studio.tsx`
- 見た目のコード: `src/components/geometry-studio.css`
- ページ設定: `src/routes/geometry.tsx`
- 出力形式: SVGファイル

## まず覚えること

### 円周率 π

円周率は「円のまわりの長さ ÷ 円の直径」の値です。ここでは約 `3.14159265`として使っています。

子どもの例:

> まわりを3回以上たどったら、少し余る。これが円周率のイメージです。

お年寄り向け:

> 円周率は円を計算するときの大切な数字です。画面では小数点以下を短く表示していますが、内部ではコンピューターの精度で計算しています。

### X・Y・Z

形は、上下左右だけでなく奥行きのある見え方をします。アプリでは次の3方向で回します。

| 軸 | ざっくりした意味 | スライダーを動かすと |
|---|---|---|
| X | 横切る上下方向の回転 | カエルが前後にお辞儀するように見えます |
| Y | 左右方向の回転 | 箱を横から見直しているように見えます |
| Z | 正面から時計回りの回転 | 図形を画面の中央に置いて回します |

「X」は下の名前ではありません。向きを決める名前です。

### クラインの壺

クラインの壺は、数学で知られる形です。普通のコップとは違い、表と裏がつながっているように見える形です。ここでは最初の少し難しい形でもあります。

このアプリでは表面を線の網目で表示しています。本物の立体模型ではなく、紙の上に見やすく描いた「平面への投影」です。

### 円

円は半径を使って描きます。円周率πと半径から円の面積や円周を考えられます。

- 円周: `2 × π × 半径`
- 円の面積: `π × 半径 × 半径`

### 立方体

立方体は縁が12本ある立体です。頂点は8個あります。今は面を塗らず、12本の線だけで見せています。

## 画面の使い方

1. `/geometry`を開く。
2. 左の「Objects」で使う形を選ぶ。
   - `Klein bottle`
   - `Circle`
   - `Cube`
3. `X`・`Y`・`Z`のスライダーで形を回す。
4. `Scale`で形の大きさを変える。
5. `Link Z rotation to clock seconds`をオンにすると、Z軸が時計の秒と連動する。
6. `Export SVG`を押すと、現在の図をSVG画像として保存する。

## 時計との連動

時計の秒は0〜59です。このアプリはそれを角度に変換します。

```text
角度 = 秒 × 6
範囲 = 0度から354度
```

なぜ6をかけるのか:

```text
360度 ÷ 60秒 = 6度
```

つまり、時計が1秒進むごとに、Z軸は約6度回ります。

## 数式とコードの対応

度をラジアンに変える式は次の通りです。コンピューターの三角関数は「ラジアン」を使うためです。

```text
ラジアン = 度 × π ÷ 180
```

コードでは次です。

```typescript
const ax = (angles.x * PI) / 180;
```

回転後の座標を画面に写す部分は次の考え方です。

```text
画面の横位置 = 中心 + 回転後のx座標 × 拡大倍率
画面の縦位置 = 中心 - 回転後のy座標 × 拡大倍率
```

奥行きを考える簡単な遠近法も含まれています。

```typescript
const perspective = 260 / (260 + p.z * 0.22);
```

## 主要な関数の説明

### `rotate(point, angles)`

3D座標をX、Y、Z軸で回します。

覚え方:

- `ax`, `ay`, `az`は回転角度
- `point`は回す前の位置
- 戻り値は回した後の位置

### `project(point, angles, scale)`

回した3D座標を、画面上の横・縦の位置に変換します。

### `kleinPoint(u, v)`

クラインの壺の表面の1点を計算します。

- `u`は回り方向
- `v`は輪方向
- `r`は表面からの太さ

表面全体は、この点を網目状に並べています。

### `kleinMesh(angles, scale)`

クラインの壺の線をたくさん作ります。

- `steps = 18`は網目の分け方
- `count = 32`は各線を細かく分ける数

行と列を両方描くことで、網目状になります。

### `cubeEdges(angles, scale)`

立方体の8個の頂点と、12本の線を定義します。

### `exportSvg()`

画面内のSVGを探し、ブラウザーからファイルとして保存します。

この処理はサーバーへ送信しません。保存されたファイルは、このブラウザーだけが操作します。

## 応用例

### 小学生向け

- 円を1個描き、時計の秒で回す。
- スライダーを動かして、どの向きが見やすいか比べる。
- X、Y、Zをそれぞれ動かして、「回る向き」を言葉で説明する。
- 立方体の辺が全部で12本ある理由を数える。
- 1分で立方体が何回りするか予想する。

例:

> Zの角度を60°から始めると、1秒ごとに6°回る。10秒で60°回る。

### 中学生・高校生向け

- 座標、三角関数、ラジアンを練習する。
- 円周率を小数点以下の桁数を変えて表示する。
- クラインの壺の式をu/vで解析する。
- 同じ立方体を回転角の違いで8パターン描く。
- `Scale`と遠近法の式が結果へ与える影響を調べる。

応用課題:

1. 秒針が動く角度を手計算する。
2. 円周、面積、球の体積を別のセルとして追加する。
3. クラインの壺の線数を19から32に変えると描画が重くなるか観察する。

### 大学生・プログラマー向け

- 行列による回転へ置き換える。
- 深度ソートで線の重なりを自然にする。
- 法線ベクトル、陰影、ワイヤーフレームの面描画を追加する。
- クラインの壺の表面を三角形メッシュへ変換する。
- Web Workerで大量点の計算を分ける。
- Canvas 2DまたはWebGLへ移植する。
- Undo・Redo・オブジェクト選択・カメラ操作を追加する。
- 解析情報をJSONで保存し、再読み込みできるようにする。

この順番なら、ブラウザで動くかんたんな図形ツールから本格的な3Dエディターへ段階的に拡張できます。

### お絵かきへの応用

- 時計の秒を色に変換する。
- X・Yの角度で花びらの配置を作る。
- 円の半径を音量や時間に対応させる。
- クラインの壺の線を自由曲線の模様として使う。
- SVGとして保存し、色や線を別の画像ソフトで編集する。
- 同じ形を数秒ごとに保存して、簡単なアニメーションにする。

### 教育での使い方

授業では次の順序がわかりやすいです。

1. 円を回して円周率を見る。
2. 立方体の頂点と辺を数える。
3. X・Y・Zを一つずつ動かす。
4. 時計と角度の関係を計算する。
5. クラインの壺で「つながり」を考える。
6. SVGを保存して作品として発表する。

## 制約と注意点

- クラインの壶を含む形は、SVGの網目による簡易表示です。
- 現在のアプリは本格的なBlender式の編集機能ではありません。
- モデリング、影、材質、カメラ、レンダリング、ファイル読み込みはまだありません。
- 数値はブラウザー内で計算されます。
- ファイル保存以外のアップロードや外部送信は行いません。
