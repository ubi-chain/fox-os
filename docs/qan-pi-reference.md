# Qan · π リファレンス

Qan に円周率 **π** を導入しました。計算はすべてブラウザ／机の中だけで行い、外部 AI クレジットは使いません。

関連: [ジオメトリースタジオ](./geometry-studio-reference.md)

## 定数

| 名前 | 値 |
|------|-----|
| `π` / `pi` / `PI` | 円周率（内部は倍精度） |
| `τ` / `tau` | `2 × π` |
| `e` | 自然対数の底 |

## 関数 `π(...)`（ローカル入口）

| 書き方 | 意味 |
|--------|------|
| `π` または `π()` | 定数そのもの |
| `π(r)` | 円の面積 `π × r × r` |
| `π(面積, r)` | 同上 |
| `π(円周, r)` | 円周 `2 × π × r` |
| `π(度, d)` | 度 → ラジアン（`d × π ÷ 180`） |
| `π(ラジアン, x)` | ラジアン → 度 |

```text
ラジアン = 度 × π ÷ 180
```

## その他の文

```qan
print 2 * π * 10
let r = 3
π(円周, r)
say "hello"
```

## 設計方針

- **ローカル優先**: `π` はクレジット不要の計算入口
- **幾何と一致**: `/geometry` の円周率・度ラジアン変換と同じ定義
- **将来**: 同名の入口からローカル推論へ拡張してもよいが、既定経路は机の中に留める
